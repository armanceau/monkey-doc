# Writing Your First Guide

This page lives inside a `guides/` folder — which is why you can see the **breadcrumb** in the header above: `Guides / Writing Your First Guide`.

## Create a folder

Any subfolder inside `docs/` becomes a breadcrumb segment automatically.

```
docs/
  guides/
    writing-your-first-guide.mdx   ← this page
  getting-started.mdx
```

## Add frontmatter

Use the `title` and `order` fields to control how pages appear in the sidebar.

```mdx
---
title: My Guide
order: 1
---

# My Guide

Content goes here.
```

## That's it

No config needed. Monkey-Doc picks up the folder structure and builds the navigation and breadcrumb automatically.
