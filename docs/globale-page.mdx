# Global Page (no language)

This page lives at `docs/getting-started.mdx` — outside of any language folder (`en/`, `fr/`, etc.).

It appears in the sidebar **regardless of the selected language**, because Monkey-Doc treats files outside language folders as global content.

Unlike Storybook (which focuses on UI components), Monkey-Doc is built for writing
**product guides, onboarding flows, and storytelling documentation**.

## What you'll learn

In this guide you'll learn how to:

- Set up your documentation
- Write your first guide
- Use built-in components

  You're looking at a live example! These files live in your `/docs` folder.
</Callout>
