# Getting Started

<Callout type="warning">
  You are reading the **v3 documentation**. This version is in maintenance mode — only critical bug fixes will be backported. Consider upgrading to [v4](/v4/getting-started).
</Callout>

Welcome to **Monkey-Doc v3** — a narrative-first documentation tool.

## Quick Start

<Steps>

### Install

```bash
npm install -D monkey-doc@3
```

### Initialise

```bash
npx monkey-doc init
```

### Start the server

```bash
npx monkey-doc dev
```

</Steps>

## What's in v3?

- MDX rendering with syntax highlighting
- Sidebar navigation auto-generated from file structure
- Dark mode
- Table of contents
- Search (Cmd+K)
- i18n (multiple language folders)
- PDF export

## Upgrading to v4

v4 adds versioning, Charts, Mermaid diagrams, and performance improvements.

```bash
npm install -D monkey-doc@latest
```

See the [v4 docs](/v4/getting-started) for migration details.
