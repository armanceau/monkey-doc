# Composants MDX

Monkey-Doc v3 est livré avec des composants MDX intégrés utilisables sans import.

<Callout type="info">Ceci est un callout **info**.</Callout>
<Callout type="warning">Ceci est un callout **avertissement**.</Callout>
<Callout type="success">Ceci est un callout **succès**.</Callout>

## Tabs

<Tabs labels={["npm", "yarn"]}>

```bash
npm install -D monkey-doc@3
```

```bash
yarn add -D monkey-doc@3
```

</Tabs>

## Steps

<Steps>

### Installer monkey-doc

```bash
npm install -D monkey-doc@3
```

### Lancer init

```bash
npx monkey-doc init
```

### Commencer à écrire

```bash
npx monkey-doc dev
```

</Steps>
