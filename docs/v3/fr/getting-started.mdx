# Démarrage

<Callout type="warning">
  Vous consultez la documentation **v3**. Cette version est en mode maintenance — seules les corrections critiques seront portées. Passez à [v4](/v4/fr/getting-started).
</Callout>

Bienvenue sur **Monkey-Doc v3** — un outil de documentation narratif.

## Démarrage rapide

<Steps>

### Installer

```bash
npm install -D monkey-doc@3
```

### Initialiser

```bash
npx monkey-doc init
```

### Démarrer le serveur

```bash
npx monkey-doc dev
```

</Steps>

## Ce qu'inclut v3

- Rendu MDX avec coloration syntaxique
- Navigation sidebar générée automatiquement
- Dark mode
- Table des matières
- Recherche (Cmd+K)
- i18n (dossiers de langues multiples)
- Export PDF

## Passer à v4

v4 ajoute le versioning, les graphiques Chart.js, les diagrammes Mermaid et des améliorations de performance.

```bash
npm install -D monkey-doc@latest
```
